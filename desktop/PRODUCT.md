# Product

## Platform

web

Rift для Windows 10/11 x64: Tauri 2, React/TypeScript, WebView2.
`web` обозначает технологию интерфейса по схеме Impeccable, не отдельную браузерную
версию. Мобильная версия и полноценная поддержка Linux/macOS не входят в этот продукт.

## Users

Пользователь получил подписку или данные сервера и хочет подключиться.
Знание VLESS, Reality, Endpoint, Proxy и TUN не требуется.

## Product Purpose

Добавить свои серверы или подписку, подключиться, поручить дальнейший выбор
рабочего сервера автоматике. Состояние соединения и действие при ошибке должны
быть понятны без изучения журнала проверок.

Rift не продаёт доступ; каталога поставщиков и учётных записей нет.

## Positioning

Автовыбор сначала подключает первый рабочий сервер, затем завершает проверки
и выбирает сервер с минимальной измеренной задержкой через прокси.
Периодические проверки сравнивают текущий сервер с кандидатами с учётом порогов
переключения. Сама проверка другого сервера не должна переключать пользовательский
трафик. Максимальная скорость и бесперебойность не гарантируются; превосходство
над другими клиентами не заявляется.

## Operating Context

Интерфейс русский. Разделы: «Подключение», «Серверы», «Соединения»,
«Маршрутизация», «Настройки», «Журнал». Подписка в «Серверах» служит источником;
подключение использует конкретный сервер.

Основной путь: добавить данные → подключиться → видеть состояние.
Ручной выбор, проверки и диагностика доступны при необходимости.
Закрытие окна скрывает Rift в трей; «Выход» завершает приложение и собственные ядра.

## Capabilities and Constraints

- VLESS/Reality, VMess, Trojan и Shadowsocks; ручные серверы и подписки,
  обновление подписок, ручной выбор и автовыбор.
- Ручной выбор не выключает автовыбор: выбранный сервер сравнивается с остальными.
  Проверки, переключения, расписание, хранение данных и сетевой процесс принадлежат
  Rust; React показывает состояние и передаёт действия пользователя.
- Proxy (по умолчанию), TUN и TUN + Proxy. HTTP/SOCKS5-прокси слушает только
  loopback; системный прокси Windows не меняется. TUN требует прав администратора.
- Системная, светлая и тёмная темы. Полный профиль не шифруется и содержит
  секреты; экспорт требует предупреждения, импорт требует подтверждения замены данных.
  Ошибка не должна уничтожать рабочие данные.
- URI, ссылки подписок, пароли, UUID, токены и сырой вывод сетевого процесса
  не попадают в журнал. Причины и технические сведения сохраняются только локально
  после очистки и ограничения размера. Автоматической отправки диагностики нет; ручной экспорт
  требует предупреждения о приватности.
- Обычные ошибки фоновых задач сразу записываются в основной журнал.
  Паники сначала попадают в crash-журнал: до 16 записей по 128 КиБ с учётом
  JSON-экранирования, подробности каждой до 16 КиБ. Записи объединяются с основным
  журналом при обработке уведомления, записи, экспорте или следующем запуске.
  Если сбой произошёл внутри очистки секретов, подробности скрываются.

## Brand Commitments

Все собственные данные, включая WebView2, хранятся в `data` рядом с программой.
Определение страны удалено, имя провайдера сохраняется. Версия в футере,
верхнее меню закреплено при прокрутке.

Название: Rift. Пользовательские сообщения на русском. Знак:
`src-tauri/icons/source.svg`; текущее оформление: токены `src/theme.css`.

## Evidence on Hand

- Экраны: `src/`; production stories: `src/App.stories.tsx`
  и `src/components/*.stories.tsx`.
- Visual baselines: `e2e/screens.spec.ts-snapshots/`, размеры 1280×820 и 1000×680.
  Storybook из корня репозитория: `pnpm --dir desktop storybook`.
- Браузерные тесты и Storybook не проверяют Windows routing, установщик
  и настоящее сетевое соединение. Для них нужна ручная проверка на Windows.

## Product Principles

1. Состояние и подключение понятны без сетевых терминов; подробности проверок
   и расширенные настройки не мешают основному пути.
2. Автоматика выбирает сервер, явный ручной выбор становится текущим сервером.
3. Ошибка сохраняет рабочие данные и объясняет следующее доступное действие.
4. Показываются реальные измерения и состояния. Фиктивные задержки допустимы
   только в тестах и Storybook.

## Accessibility & Inclusion

Основной путь доступен с клавиатуры, фокус видим, поля подписаны.
Состояния передаются текстом, не только цветом; нужные пользователю пояснения
доступны не только по наведению. Проверяются обе темы и оба размера окна.
Автоматические проверки не означают сертификацию доступности.
