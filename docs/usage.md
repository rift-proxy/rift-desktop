# Как пользоваться

## Добавить серверы

1. Получите ссылку сервера или HTTPS-подписку у провайдера. Rift их не выдаёт.
2. Откройте «Серверы» -> «Добавить сервер» или «Добавить подписку». Ссылку сервера можно вставить через Ctrl+V на этой странице; подтвердите импорт в диалоге.
3. У подписки дождитесь загрузки. «Обновить все» запрашивает подписки заново. Фильтры названий и протоколов меняются в её настройках и применяются при обновлении.
4. На странице «Подключение» выберите сервер и нажмите «Подключиться».

## QR-коды и ссылки `rift://`

В диалоге импорта прочитайте QR-код с изображения или из буфера обмена. Он должен содержать ту же ссылку сервера или подписки, которую можно вставить текстом. Rift покажет найденные данные и попросит подтверждение.

Сайт провайдера может открыть установленный Rift:

- `rift://add?url=<HTTPS-подписка>` открывает добавление подписки.
- `rift://add?uri=<ссылка-сервера>` открывает добавление сервера.

Закодируйте значение `url` или `uri` как один URL-параметр. Например, тестовая подписка `https://provider.example/sub` превращается в `rift://add?url=https%3A%2F%2Fprovider.example%2Fsub`. Вложенные `&`, `?` и `#` тоже нужно закодировать, иначе изменится смысл внешней ссылки. Принимается ровно один параметр, `url` или `uri`, без дополнительных.

Установщик Windows регистрирует схему для текущего пользователя. Если Rift уже запущен, ссылка откроет его окно. Без подтверждения ничего не добавится; подключение не переключится. У схемы нет команд подключения, изменения настроек или запуска программ: это не API удалённого управления.

Ссылки могут содержать пароли и токены. Не публикуйте настоящие ссылки в issue, PR, документации или общедоступных QR-кодах.

## Режим работы

Выберите режим в «Настройки» -> «Режим работы». Текущий режим виден на странице «Подключение».

- Proxy: локальный HTTP/SOCKS5-прокси. Скопируйте показанный адрес в настройки приложения. Системный прокси Windows не меняется; остальные приложения сами через Rift не пойдут.
- TUN: виртуальный сетевой интерфейс; трафик направляют правила маршрутизации. Локальный прокси выключен.
- TUN + Proxy: виртуальный интерфейс и локальный прокси вместе.

Без прав администратора TUN запрашивает UAC для помощника при каждом подключении. Отказ переводит Rift в Proxy: настройте прокси в приложении. Постоянно запускать весь интерфейс от администратора не нужно. [Как вернуть TUN после отказа](troubleshooting.md#отказали-uac-tun-не-включился).

## Автовыбор и ручной выбор

«Автовыбор сервера» сравнивает доступные серверы и может сменить текущий. Пока пул рабочих серверов заполняется, выбирается лучший. При полном пуле переход со стабильно работающего сервера на более быстрый требует достижения обоих порогов смены из настроек. Проверки «До сервера» и «Через сервер» различаются: доступный TCP-порт ещё не доказывает доступ в интернет.

Ручной выбор не выключает автовыбор. Чтобы остаться на выбранном сервере, выключите «Автовыбор сервера» сами. Тогда при потере соединения другой сервер нужно выбрать вручную или снова включить автовыбор. «Проверить сейчас» запускает проверку.

## Маршрутизация

В «Маршрутизации» три списка: `Block` блокирует трафик, `Direct` направляет мимо сервера, `Proxy` через выбранный сервер.

В «Порядке проверки» первые два списка проверяются по очереди, последний получает весь оставшийся трафик. Его сохранённые записи пока не применяются. Если последним стоит `Block`, весь несовпавший трафик блокируется.

Добавляйте по одной записи на строку, например `domain:example.com` или `process:chrome.exe`. Синтаксис показан на странице. Для сайтов в Proxy используйте доменные правила: IP-правила требуют соединений с известным IP. Для `geosite:` и `geoip:` сначала загрузите базы кнопкой «Обновить базы».

Нажмите «Применить». Изменение действующих правил перезапустит активное соединение; ошибка проверки сохранит прежнюю маршрутизацию. Правка только записей последнего списка не меняет действующие правила и не требует перезапуска. «Вернуть по умолчанию» заменяет ваши списки и порядок. При включённых «Применять маршруты провайдера» ваши списки главнее правил из Xray JSON.

## Профиль и выход

«Настройки» -> «Профиль» -> «Экспортировать» сохраняет настройки, серверы и подписки. «Импортировать» проверяет файл и просит подтвердить замену текущего профиля.

Профиль не шифруется: в нём есть пароли серверов и ссылки подписок. Не публикуйте его и не прикладывайте к обращениям; храните копию с ограниченным доступом. То же относится к `data/state.json`.

Закрытие окна оставляет Rift в трее. Полная остановка — «Выход» в трее.
