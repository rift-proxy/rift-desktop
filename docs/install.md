# Установка

Rift поддерживает Windows 10 и 11 x64.

1. В [Releases](https://github.com/rift-proxy/rift-desktop/releases) скачайте `Rift_<версия>_x64-setup.exe`
2. Запустите установщик. Rift устанавливается для текущего пользователя.
3. В разделе «Серверы» добавьте ссылку сервера или HTTPS-подписку своего провайдера и подключитесь. Rift не выдаёт серверы или подписки.

## WebView2

Для интерфейса нужен Microsoft Edge WebView2 Runtime. Если его регистрации нет в Windows, установщик скачает его самостоятельно с сайта Microsoft. Для этого нужен интернет, офлайн установщика нет. Ошибка загрузки или установки WebView2 прервёт установку.

Если регистрация осталась, а Runtime повреждён или удалён, проверка может этого не заметить. Если Rift не открывается после установки, восстановите или переустановите [WebView2 Runtime с сайта Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/#download).

## Proxy и TUN

По умолчанию выбран Proxy. Укажите `127.0.0.1:2080` как HTTP- или SOCKS5-прокси в нужном приложении; порт меняется в настройках. Rift не меняет системный прокси Windows. Приложения без своей настройки прокси автоматически через него не пойдут.

TUN направляет трафик через виртуальный сетевой интерфейс. TUN + Proxy добавляет локальный прокси. Без прав администратора Windows при каждом подключении запросит UAC для помощника. Отказ переводит Rift в Proxy. Постоянно запускать весь интерфейс от администратора не нужно. Подробнее о [режимах работы](usage.md#режим-работы).

Закрытие окна оставляет Rift в трее. Для остановки программы и обоих её ядер выберите «Выход» в трее.

## Данные и обновления

Настройки, серверы, подписки, журнал, данные WebView2 и временные файлы обновления хранятся в `data` рядом с EXE. Папка установки должна быть доступна на запись. При переносе прежних данных оригиналы не удаляются.

Для переноса или резервной копии выйдите из Rift через трей и сохраните всю папку `data` рядом с EXE (при стандартной установке — `%LOCALAPPDATA%\Rift\data`). В `state.json` реквизиты серверов и ссылки подписок записаны открытым текстом. Обновление и удаление Rift сохраняют `data`. Для полного удаления данных удалите её сами.
